Metodología (scoring v1, heurístico)

  1. Requisitos duros: sin género común o sin plataforma común no hay competidor.
  2. Género (peso 3): 1.0 con ≥2 equivalentes, 0.6 con 1. Tabla RAWG↔IGDB documentada.
  3. Plataforma (peso 2): 1.0 con ≥2 en común, 0.5 con 1.
  4. Era (peso 1): 1.0 si ≤2 años, 0.5 si ≤4, 0 si más o sin fecha (ausente = 0).
  5. Estudio (peso 1): solo si ambas partes lo tienen; si no, no aplica ni penaliza.
  6. Tiers: ≥0.75 directo · ≥0.45 secundario · ≥0.25 relacionado.

Cada competidor muestra qué aportó cada componente. Subgénero, modelo de negocio y audiencia están excluidos por falta de fuente válida. Popularidad solo como contexto dentro de cada fuente.
